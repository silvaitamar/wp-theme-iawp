# Playground — IA+WP theme demo

Zero-install lab that mirrors the public hub layout:

- Theme `iawp` (this repo)
- [Block Header Behavior](https://github.com/silvaitamar/block-header-behavior) (header overlay)
- [Jetpack](https://wordpress.org/plugins/jetpack/) (contact form / newsletter CTA)
- [Social Sharing Block](https://wordpress.org/plugins/social-sharing-block/)

## Notes

- Editorial titles/excerpts match the public site; single bodies are short demos with links to production articles.
- Legal pages are short demo stubs (full text stays on production).
- Jetpack runs with `JETPACK_DEV_DEBUG` — the form renders; real delivery / WordPress.com connection are out of scope.
- Ops plugins (cache, security, CDN) are not installed.
